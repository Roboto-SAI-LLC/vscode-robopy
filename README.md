# RoboPy

VS Code language support for **RoboPy** — Roboto speaking this dialect.

Origin: `class Roberto` then `roboto = Roberto()`. Two names that rhyme. Type is the maker. Value is the being.

## Install

1. Download the `.vsix` from the Roboto studio (Export → VS Code), or clone this repo.
2. In VS Code: **Extensions → ⋯ → Install from VSIX…**
3. Open a `.rp`, `.robopy`, or `.rpy` file.

Marketplace / Open VSX: this package is `robotosai.robopy`. Publishing uses `vsce publish` with a publisher token.

## What it teaches

Hover any keyword. The hover is the same lesson as the studio — what the word *does*, and the Python cousin.

| Role | Word | Python |
| --- | --- | --- |
| Function | `def` | def |
| If | `if` | if |
| Else if | `elif` | elif |
| Else | `else` | else |
| While | `while` | while |
| For | `for` | for |
| In | `in` | in |
| Return | `return` | return |
| Print | `print` | print |
| True | `True` | True |
| False | `False` | False |
| Null | `None` | None |
| And | `and` | and |
| Or | `or` | or |
| Not | `not` | not |

## File types

`.rp` `.robopy` `.rpy`

## Publish

Languages live in three places:

1. **This GitHub repo** — source of truth
2. **VS Code Marketplace** / **Open VSX** — where editors find extensions
3. **GitHub Linguist** — syntax color on github.com (send a PR to [github-linguist](https://github.com/github-linguist/linguist) with the YAML in `linguist.yml`)
